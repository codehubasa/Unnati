🌐 Unnati

🚀  A Data-Driven Gram Panchayat Governance Platform

Unnati is a scalable civic-tech platform that digitizes rural governance by connecting citizens, Panchayat officials, and government administrators through a unified, data-driven system.
________________________________________
📌 Problem Statement

Rural governance systems often face:
•	 Lack of transparency in issue resolution 
•	 Delayed communication between citizens and authorities 
•	 No centralized monitoring system 
•	 Limited citizen engagement 
________________________________________
💡 Solution

Unnati provides a multi-role digital ecosystem where:
•	Citizens can report real-time issues 📢 
•	Panchayat officials can manage and resolve them ⚙️ 
•	Government admins can monitor performance with insights 📊 
________________________________________
🎯 Key Highlights

•	🔐 Role-Based System (Citizen / Panchayat / Admin) 
•	📊 Real-Time Analytics Dashboard 
•	🧠 AI-Based Insights for Governance 
•	🌍 Multi-language Support (English + Hindi) 
•	🏆 Citizen Engagement via Impact Score 
•	📌 End-to-End Issue Lifecycle Tracking 
________________________________________
🧩 Features Breakdown

👤 Citizen Module

•	Submit complaints with category & description 
•	Upload images/videos as proof 
•	Track issue status (Pending / In Progress / Resolved) 
•	Citizen Impact Score (gamification for engagement) 
________________________________________
🏛️ Panchayat Dashboard

•	View and manage incoming requests 
•	Update issue status (Start Work / Resolve / Reopen) 
•	Monitor performance metrics 
•	Analyze citizen feedback and ratings 
________________________________________
🌍 Government Admin Panel

•	National-level analytics overview 
•	Identify top-performing Panchayats 🥇 
•	Detect underperforming regions ⚠️ 
•	AI-powered recommendations for policy actions 🤖 
•	Budget and project monitoring insights 
________________________________________
🖼️ Project Preview

🔐 Multi-Role Login System
Clean and intuitive role-based access interface.
📝 Citizen Reporting System
Structured complaint submission with media upload and priority tagging.
📊 Panchayat Dashboard
Performance tracking with real-time issue management.
🌍 Admin Analytics Panel
Data-driven insights with alerts, rankings, and AI recommendations.
